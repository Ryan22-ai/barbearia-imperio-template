# ✂️ Barbearia Império - Landing Page Template

Landing page moderna de alta conversão projetada para barbearias e comércios locais, focada em experiência mobile e agendamento rápido via WhatsApp.

## 🚀 Tecnologias Utilizadas
- **HTML5** (Estrutura semântica)
- **Tailwind CSS** (Estilização via CDN)
- **JavaScript (ES6+)** (Menu mobile e interatividade)
- **FontAwesome 6** (Iconografia)

## 📌 Funcionalidades
- Layout Dark Mode com detalhes em dourado
- 100% Responsivo (Mobile First)
- Links de CTA dinâmicos integrados ao WhatsApp
- Seção de Serviços com indicação de destaque (Combo)
- Localização integrada via Google Maps
